The Names He Carried

The life of Laurence Brown Douglas, from Edinburgh in 1907 to Rhode Island. A narrative biography with its full record archive, case files, a short documentary film and an audiobook.

HTML5CSS3JavaScriptPythonJSONGitHub Pages
How it's built
  • Static website hosted on GitHub Pages; no server, nothing to break.
  • Every chapter stored as structured data (JSON) and laid out in the browser.
  • A 40-person index drives the people list down the side of every page.
  • Full-text search: a Python script builds a search index that runs right in the browser.
  • Audiobook chapters voiced in ElevenLabs and served as MP3s.
  • A short documentary film cut from the original records and photos.
  • Record archive and Cold Case File with word-for-word transcriptions of every document.

Amadeus School of Drums

A complete drum school: three lesson levels, the 40 rudiments, a playable vintage drum set and a 59-instrument percussion room, all with real recorded sound.

HTML5CSS3JavaScriptWeb Audio APIWeb MIDI APIService WorkerPythonGitHub ActionsSupabase
How it's built
  • Static HTML, CSS and JavaScript on GitHub Pages under its own domain.
  • Custom audio engine on the Web Audio API playing 600+ real recorded drum and percussion samples.
  • Velocity layers and slight timing variation so grooves sound played, not programmed.
  • Web MIDI support: plug in an electronic drum set and play the site.
  • Notation that lights up in time with the playback.
  • Installable as an app (service worker, works offline).
  • Drum news refreshed every 4 hours by GitHub Actions running Python fetchers.
  • Supabase back end for the drum chat; FormSubmit contact form; Buttondown newsletter.

AI Sentry

Scans a computer for AI apps, agents and AI-attack risks, with a command-center dashboard of what it finds.

Python 3macOSHTML reportJSONMITRE ATLASOWASP LLM Top 10NIST CSF 2.0
How it's built
  • Python 3 scanner, a single file of about 800 lines with nothing to install.
  • Runs from one Terminal command on macOS; read-only, sends nothing over the internet.
  • Finds AI apps and the privacy permissions they hold.
  • Checks AI browser extensions in Chrome, Brave, Edge, Arc, Vivaldi and Firefox.
  • Inspects AI agent tool servers (MCP) for Claude, Cursor, Windsurf, VS Code, Zed, Gemini CLI, Codex and Cline.
  • Hunts for exposed AI keys (OpenAI, Anthropic, Google, Hugging Face and more) in files and shell history.
  • Detects hidden prompt-injection text in documents, and local AI servers such as Ollama and LM Studio.
  • Red, yellow and green report in HTML and JSON, mapped to MITRE ATLAS, OWASP Top 10 for LLM Applications and NIST CSF 2.0.

Island News Media Productions

The company behind the publications: arts, entertainment and community news for Rhode Island, Boston and New York City.

HTML5CSS3JavaScriptPython 3.12GitHub ActionsJSONRSSPillowPWA
How it's built
  • Four publications running on one shared template, each with its own domain and accent color.
  • Static HTML and JavaScript on GitHub Pages, with all content in JSON data files.
  • GitHub Actions run Python jobs on a schedule, no staff needed for the routine work:
  • Hourly marine conditions from NOAA buoys, National Weather Service marine forecasts and Coast Guard notices.
  • Daily job boards pulling USAJobs, state and school job systems, and company hiring boards (Greenhouse, Lever, Ashby, Workable).
  • Daily checks that drop closed or expired event listings, plus calendar cleanup.
  • Automatically generated share cards for every story (Pillow) and a banned-words check before anything publishes.
  • RSS feed and installable app on every edition.
