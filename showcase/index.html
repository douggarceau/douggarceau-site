AI Sentry

Developed by Doug Garceau

Scans a computer for AI apps, AI agents and AI-attack risks, then explains every finding in plain language with a fix.

  • Finds AI tools that can run commands, change files or send email
  • Catches exposed AI keys and booby-trapped documents
  • Read-only: nothing leaves the computer
  • Every finding mapped to MITRE ATLAS, OWASP and NIST
View the sample reportView the source
Technical details
  • Python 3 standard library only (~800 lines, single module, zero dependencies); runs from one Terminal command.
  • Read-only inspection with no network egress: the report shows 0 bytes sent.
  • Enumerates installed apps and macOS privacy (TCC) permissions; Full Disk Access unlocks the deep scan.
  • Parses Chromium and Firefox profiles to flag AI extensions that can read every site.
  • Parses MCP tool-server configs (Claude, Cursor, Windsurf, VS Code, Zed, Gemini CLI, Codex, Cline) and flags shell, file-write and email capability.
  • Pattern-based secret scanning for AI provider API keys across dotfiles, shell history and project trees.
  • Prompt-injection heuristics over HTML, text, DOCX, PPTX, XLSX and PDF: hidden text, zero-width characters, invisible styling.
  • Checks local inference servers (Ollama, LM Studio, Jan, GPT4All) for exposure to other computers on the network.
  • Severity-scored HTML report plus machine-readable JSON; each finding mapped to MITRE ATLAS, OWASP Top 10 for LLM Applications and NIST CSF 2.0 (see the sample report).

Ghost Wealth Systems

Developed by Doug Garceau

A private financial terminal and a public world market desk: markets, official releases, filings and news, with nothing invented.

Open the market desk
Technical details
  • Node.js 22 application with two isolated builds: a private owner terminal and a public market desk.
  • Bundled with esbuild into Cloudflare Workers (workerd) deployments; a build guard refuses to ship private code or keys in the public bundle.
  • OIDC sign-in, signed session cookies and hardened security headers on the private terminal.
  • Public data only: Coinbase Exchange snapshots, Federal Reserve, BLS and BEA releases, SEC EDGAR filings and publisher news feeds.
  • Unavailable prices stay labelled unavailable, never invented; news keeps original publication dates.
  • Test suite of 129 unit, browser (Playwright) and native workerd runtime checks in GitHub Actions.

Defender

Developed by Doug Garceau

A recreation of the 1981 arcade classic that works with original-style arcade controls. The preview is the game playing itself.

Play Defender
Technical details
  • One self-contained HTML5 file (~66 KB), vanilla JavaScript, no engine or libraries.
  • Fixed-step game loop on requestAnimationFrame with Canvas 2D rendering at 60 fps.
  • Sound synthesized with Web Audio API oscillators and envelopes.
  • Keyboard and Gamepad API input for original-style arcade joystick and buttons.
  • Shared Hall of Fame on Supabase; the preview runs a built-in autopilot that never posts scores.

Amadeus School of Drums

Built by Doug Garceau

A complete drum school in the browser: a real-time audio engine, 600+ recorded samples, MIDI drum input and lessons with notation that follows the sound.

Open the drum school
Technical details
  • Custom sampler on the Web Audio API: 600+ recorded one-shots decoded into AudioBuffers.
  • Velocity layers and small timing offsets so grooves sound played, not programmed.
  • Playback scheduled against the AudioContext clock for sample-accurate timing.
  • Web MIDI input: plug in an electronic drum set and play the site.
  • Notation that lights up in time with the audio; installable app with offline cache.
  • Drum news refreshed every 4 hours by GitHub Actions running Python fetchers.

Island News Media Productions

Five city and town news sites running on one automated publishing system. Built by Doug Garceau.

How the publishing system works
  • Five editions on one shared template, each with its own domain and accent color.
  • Static HTML and JavaScript on GitHub Pages, with all content in JSON data files.
  • GitHub Actions run Python jobs on schedules: hourly NOAA and National Weather Service marine data, daily job boards (USAJobs, state and school systems, Greenhouse, Lever, Ashby, Workable).
  • Daily validators drop closed or expired listings and clean the calendar.
  • Share images generated with Pillow and a banned-words check before anything publishes.
  • RSS feed and installable app on every edition.
