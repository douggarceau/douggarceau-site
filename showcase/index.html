The Names He Carried: The Laurence Brown Douglas Story

Written and built by Doug Garceau

The life of Laurence Brown Douglas, from Edinburgh in 1907 to Rhode Island. A narrative biography with its full record archive, case files, a short documentary film and an audiobook.

HTML5CSS3JavaScriptPythonJSONGitHub Pages
Open the book →
Technical breakdown
  • Static site, zero backend; deployed to GitHub Pages via git push.
  • Content layer decoupled from presentation: chapters, people (40 records) and sources serialized as JSON and rendered client-side.
  • Offline-built inverted search index (Python build script → search-index.json), queried in vanilla JS with no third-party search dependency.
  • Audiobook pipeline: chapter text → ElevenLabs TTS → per-chapter MP3 assets.
  • Documentary film (H.264 MP4) assembled from archival scans and records.
  • Document archive with verbatim transcriptions, cross-linked by person and date.

Amadeus School of Drums

Built by Doug Garceau

A complete drum school: three lesson levels, the 40 rudiments, a playable vintage drum set and a 59-instrument percussion room, all with real recorded sound.

HTML5CSS3JavaScriptWeb Audio APIWeb MIDI APIService WorkerPythonGitHub ActionsSupabase
Open it →
Technical breakdown
  • Static HTML5/CSS3/vanilla JavaScript SPA-style pages on GitHub Pages with a custom domain; no framework.
  • Custom sampler on the Web Audio API: 600+ recorded WAV/MP3 one-shots loaded via decodeAudioData into AudioBuffers.
  • Velocity-layered sample selection plus randomized micro-timing offsets for humanized playback.
  • Playback scheduled against the AudioContext clock (currentTime) for sample-accurate timing.
  • Web MIDI API input: Note On messages mapped to kit voices, so any USB e-kit triggers the sampler.
  • Notation highlighting synced to the audio clock.
  • PWA: web app manifest + service worker cache for install and offline use.
  • CI/CD: GitHub Actions cron (every 4 hours) runs Python 3.12 fetchers that rebuild the news JSON and commit it back.
  • Supabase (Postgres + auth) back end for chat; FormSubmit endpoint for contact; Buttondown API for the newsletter.

Developed by Doug Garceau

A playable recreation of the 1981 arcade classic, built to run with original-style arcade controls.

HTML5JavaScriptCanvas 2DWeb Audio APIGamepad API

Security softwareAI SentryIn development
Developed by Doug Garceau

Scans a computer for AI apps, agents and AI-attack risks, with a command-center report of what it finds.

Python 3macOSHTML reportJSONMITRE ATLASOWASP LLM Top 10NIST CSF 2.0
  • Python 3 standard library only (~800 LOC, single module, zero pip dependencies); piped and executed via curl | python3.
  • Read-only filesystem and process inspection; no network egress.
  • Enumerates installed .app bundles and queries macOS TCC privacy permissions (Full Disk Access unlocks the deep scan).
  • Parses Chromium and Firefox profile manifests to flag AI extensions with <all_urls> host permissions.
  • Parses MCP server configs (Claude, Cursor, Windsurf, VS Code, Zed, Gemini CLI, Codex, Cline) and flags tools with shell, file-write or email capability.
  • Regex-based secret scanning for AI provider API keys across dotfiles, shell history and project trees.
  • Prompt-injection heuristics over HTML, text, DOCX, PPTX, XLSX and PDF content.
  • Port and bind-address checks on local inference servers (Ollama, LM Studio, Jan, GPT4All) to detect LAN exposure.
  • Emits a severity-scored HTML report and machine-readable JSON, findings mapped to MITRE ATLAS, OWASP LLM Top 10 and NIST CSF 2.0.

Publishing systemThe news publicationsLive
Developed by Doug Garceau

Five city and town news sites on one shared template.

HTML5CSS3JavaScriptPython 3.12GitHub ActionsJSONRSSPillowPWA
  • Multi-tenant static publishing system: one shared template, four editions, per-domain theming via CSS custom properties.
  • Content stored as JSON (calendar, gigs, jobs, marine, government, archive) and rendered client-side in vanilla JS.
  • Headless automation on GitHub Actions cron with Python 3.12 jobs; each run validates, commits and redeploys.
  • Marine ingest (hourly): NOAA NDBC buoy data, NWS marine text forecasts, USCG notices.
  • Jobs ingest (daily): USAJobs API, Workday, SchoolSpring, GovernmentJobs and ATS APIs (Greenhouse, Lever, Ashby, Workable).
  • Listing validator prunes closed or expired events; calendar normalizer fixes dates and duplicates.
  • Open Graph share images generated server-side with Pillow; banned-words lint gate before publish.
  • RSS 2.0 feed and PWA manifest on every edition.
