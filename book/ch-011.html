Quarter Notes

A quarter note is a filled-in note head with a stem. In 4/4 it gets one beat, so there are four in a bar.

EXAMPLE 11.1Alternating
TEMPO

Right, left, right, left.

EXAMPLE 11.2Right-hand lead
TEMPO

Right hand only. Keep every stroke the same height.

EXAMPLE 11.3Doubles
TEMPO

Two with each hand.

EXAMPLE 11.4On the kit
TEMPO

Hi-hat quarter notes with the right hand, bass drum with the foot on 1 and 3.

Even is everythingTIP

Record yourself playing Example 11.1. Every note should be the same volume and exactly the same distance apart.
